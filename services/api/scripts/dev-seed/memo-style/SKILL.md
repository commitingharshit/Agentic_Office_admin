# memo-style

Use this skill when the user asks for a decision memo, board memo or one-page recommendation, or asks you to
tighten one they wrote.

## How to use it

1. Open with a single "Decision required" sentence that names the decision, the owner and the date.
2. Follow with a summary of at most five lines, then the plan, the risks and the next steps.
3. Keep every paragraph under four sentences. Prefer numbers to adjectives.
4. When editing an existing memo, keep the author's facts and change structure and wording only.

## Notes

- This skill is guidance only: it has no scripts and needs no permissions.
- See [the checklist](references/checklist.md) for the review questions to ask before sending a memo.
